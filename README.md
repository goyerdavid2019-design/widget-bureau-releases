# Widget Bureau

Installateur et mises à jour du widget de bureau Widget Bureau, pour Windows 10 et 11.

## Installer

1. Télécharger **[Widget-Bureau-Setup.exe](https://github.com/goyerdavid2019-design/widget-bureau-releases/releases/latest/download/Widget-Bureau-Setup.exe)** (dernière version).
2. L'ouvrir. Windows peut afficher « Windows a protégé votre ordinateur », car l'installateur n'est pas signé : cliquer sur **Informations complémentaires**, puis **Exécuter quand même**.

L'installation ne demande pas de droits administrateur : le widget s'installe pour l'utilisateur courant, se lance tout de suite, puis démarre avec Windows.

## Mises à jour

Le widget les installe tout seul : il vérifie au démarrage puis toutes les 3 heures, télécharge la nouvelle version en arrière-plan et l'installe dès qu'il n'est pas utilisé (il se relance à la même place en quelques secondes). La version installée est indiquée en bas de son menu (bouton ⋮ ou clic droit).

Ce dépôt ne contient que les versions publiées ; elles sont listées dans [Releases](https://github.com/goyerdavid2019-design/widget-bureau-releases/releases).
